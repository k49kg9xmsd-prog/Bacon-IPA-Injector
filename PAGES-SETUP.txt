Bacon IPA Injector V1.2 — GitHub Pages 修復包

問題：GitHub 儲存庫沒有根目錄 index.html，GitHub Pages 顯示 README 而非上傳介面。

最簡單修復：
1. 下載 index.html（不要改名）。
2. 開啟 https://github.com/k49kg9xmsd-prog/Bacon-IPA-Injector
3. Add file > Upload files，選擇 index.html，Commit changes 到 main。
4. Settings > Pages > Build and deployment: Deploy from a branch > main > /(root) > Save。
5. 開啟 https://k49kg9xmsd-prog.github.io/Bacon-IPA-Injector/

根目錄 index.html 不需要 style.css、app.js、config.js，就能顯示完整上傳介面。
但要真的注入 IPA，還需要 Render 等具有 Python/zsign 的後端。請依網頁上「怎樣部署後端」的說明。

本修復包同時提供 docs/index.html，供 Pages 選 /docs 時使用。
前端已新增後端網址輸入欄，不需再手動改 JS。後端網址只保存在瀏覽器，網站密碼不儲存。

請勿把真實 IPA、dylib、私鑰、憑證或密碼上傳到公開的 GitHub 儲存庫。
